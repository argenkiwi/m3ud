NodeFactory returns Node<S,N>, whose result is Next | Promise<Next>, so tests should always `await` the node result before indexing it (the ambler testing guide says the same). A node that needs no state declares `export type State = object;`: Biome bans `{}` and rewrites an empty interface to it, and `Record<string, never>` would reject the walk State. Stdin gotcha (originally hit under Deno, kept after the move to Bun): a stdin reader left flowing in the background keeps the process alive after the last prompt while a terminal is attached. utils/prompt.ts resumes process.stdin only while a line is awaited, pauses it again after each chunk, and buffers leftover bytes so piped input is not lost between prompts. Verify with a pty (`script -q /dev/null bun walks/m3ud.ts …`), not only a pipe. When timing exit behaviour, `(sleep N) | cmd` always takes N seconds; compare against a timeout instead.
