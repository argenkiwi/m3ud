NodeFactory always returns Node<S,N>, whose return type is Next | Promise<Next>. A synchronous node test that indexes result[0] directly fails deno check (TS7053), even though the ambler-node skill template shows exactly that. Rather than narrowing in tests, make the node async and await in tests. Also: Deno prompt() returns null when stdin is not a TTY, so y/n loops built on it silently read EOF when input is piped; read lines from Deno.stdin.readable via TextLineStream instead (see m3ud utils/prompt.ts).
