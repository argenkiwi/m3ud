NodeFactory always returns Node<S,N>, whose return type is Next | Promise<Next>. A synchronous node test that indexes result[0] directly fails deno check (TS7053), even though the ambler-node skill template shows exactly that. Rather than narrowing in tests, make the node async and await in tests. Stdin gotchas: Deno prompt() returns null when stdin is not a TTY, so y/n loops built on it silently read EOF when input is piped. But do NOT replace it with a stream over Deno.stdin.readable (e.g. TextLineStream): the stream keeps a read pending in the background, so the process never exits after the last prompt while a terminal is attached. Call Deno.stdin.read() only while a line is awaited and buffer the leftover bytes (see m3ud utils/prompt.ts). When timing exit behaviour, note that `(sleep N) | cmd` always takes N seconds regardless of cmd; time cmd inside the pipeline instead.
